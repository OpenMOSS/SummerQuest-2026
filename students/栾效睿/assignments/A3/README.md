# A3 Scaling Law 实验报告：栾效睿

> 本报告只使用截止时间前已经完成的实验及离线审计结果；截止后没有发起新的训练或 API
> 调用。数值中的 `N` 均指远端返回的 `N_no_embedding`，而 API 计算量仍按远端总参数量
> 计算。报告不包含 API 地址、凭据、训练数据、权重、完整日志或隐藏评测内容。

## 结论摘要

早期 13 点加性模型在样本内和普通逐点留一上看似稳定，但在 Stage5 的预注册高数据量盲测
中系统性低估 loss，因而**不能作为可信的全局** `Loss(N_no_embedding, D)` **外推模型**。
将 5 个 Stage5 点并入后重新拟合的全局加性模型同样没有通过按模型结构留出的诊断；不以
“删除小 D 点”后变小的训练残差作为证据。最终只保留一个有条件的、结构锚定的数据尾部
外推：L6/d384 的候选预测为 **8.1773**，经验 80% 区间为 **[7.1562, 9.1984]**。这是高风险
的工程候选，不是已由全局 scaling law 证明的结论，且没有对应的 48 小时最终提交/完成记录。

## 1. 实验设计与完成情况

### 1.1 设计原则

1. 先用不同深度/宽度、不同数据量形成等计算量附近的网格，寻找稳定的学习率和 batch size。
2. 主拟合统一固定为 `learning_rate=0.0032`、`train_batch_size=2`，避免把超参数差异混入
   `N,D` 效应；每个完成运行均做 10 次验证评估。
3. Stage3 的两个新坐标保持为独立验证，不进入早期 13 点主拟合。
4. 发现早期外推的理论下限与高 `D` 观测矛盾后，追加 Stage2 calibration 与 Stage5：后者预先
   固定在小模型数据轴上加密采样，并用一个 L3 点检验从 L2 数据尾部向相邻结构转移是否合理。
5. 仅把状态为 `completed` 的远端 `final_validation_loss` 作为拟合/验证证据；失败或超时运行
   只用于稳定性和预算诊断。

### 1.2 阶段与预算审计

| --- | --- | --- |
| Stage1 | 4 次小规模配置与吞吐探测。 | 用于确定远端参数口径和时间量级。 |

## 2. Scaling-law 拟合、盲测与诊断

### 2.1 全局加性模型和早期结论

早期主模型使用非负约束的加性幂律：

$$
\hat{L}(N, D) = L_{\infty} + A_NN^{-\alpha} + A_DD^{-\beta}.
$$

冻结的 13 点 envelope 拟合得到：

$$
(L_{\infty}, A_N, A_D, \alpha, \beta)
= (0.2564,\; 921.1643,\; 51.1582,\; 0.5451,\; 0.09482).
$$

训练残差本身并未暴露问题：RMSE 为 0.2384，逐点 LOO MAE 为 0.2994，按结构留出的 LOO
MAE 为 0.2951。早期只有 9 个点时冻结预测在 Stage3 的两个区间均未命中；补充校准形成
13 点后，对同两点的离线复核变为命中，但这只覆盖到最大 `D/N=44.91`，不能验证目标区间。

更关键的是，Stage5 保持早期模型冻结后进行盲测，结果如下：

| Stage5 点 | 实际 loss | 冻结加性模型预测 | 绝对误差 |
| --- | ---: | ---: | ---: |
| L2, D=11.817M | 12.2739 | 12.0707 | 0.2032 |
| L2, D=20.972M | 11.8022 | 11.4868 | 0.3154 |
| L2, D=118.149M | 11.1372 | 9.9069 | 1.2303 |
| L3, D=118.149M | 10.5278 | 9.4740 | 1.0539 |
| L2, D=596.685M | 10.7998 | 8.6438 | 2.1560 |

普通 MAE 为 0.7007，刚好超过预设阈值 0.7；最高 D 点误差 2.1560，超过阈值 1.0。因此早期
全局加性拟合被拒绝用于最终高数据量外推，而非仅因视觉上“曲线不平滑”。

### 2.2 重新拟合的比较

将早期 13 个主点和 5 个 Stage5 点合并为 18 点；Stage3 仍不进入重拟合。以下诊断中的
“结构 LOO”是整类模型结构留出后再预测该类，检验从已见结构向未见结构泛化的能力。

| 模型/用途 | 证据 | 样本内/逐点诊断 | 结构或盲测诊断 | 判断 |
| --- | --- | --- | --- | --- |
| 冻结 13 点加性幂律 | 13 点 | RMSE 0.2384；LOO MAE 0.2994 | Stage5 高 D 误差 2.1560，失败 | 拒绝作为最终全局模型 |
| 18 点全局加性重拟合 | 13+5 点 | `L_inf=0`（下界）、`alpha=0.0500`、`beta=0.2453`；RMSE 0.3553；LOO MAE 0.3906 | 结构 LOO MAE 14.943；最高 D 留出误差 0.9637 | 不稳健，不采用 |
| 比值模型（`N` 与 `D/N`） | 冻结盲测 + 18 点诊断 | 冻结盲测 MAE 0.6430，高 D 误差 0.6584，均通过各自阈值 | 结构 LOO MAE 1.3179 | 比加性模型好，但仍非可靠全局律 |
| 结构锚定尾部模型 | L2 数据轴 + L3 转移 + L6 锚点 | L2 局部尾部 `beta=0.4129`，局部 RMSE 0.0393 | L3 数据下降量误差 0.0782，小于预设 0.6 | 仅作为最终 L6 候选的条件外推 |

18 点全局加性重拟合的 `L_inf` 撞到 0 下界，且一旦整体留出 L2 结构，误差陡增。这说明参数
可以在当前点集内补偿，但模型没有稳定地把“结构差异”和“数据量尾部”分开。另一份把
`loss<=14`、`D/N>=3`、`D>=5M` 后剩余 11 点的后验筛选拟合虽得到 RMSE 0.1887、LOO MAE
0.2055，却把 `L_inf` 撞到人为下界 1.5，结构 LOO MAE 达 16.067；该结果属于探索性敏感性
分析，不是最终证据，也没有用来选择最终配置。

### 2.3 最终采用的局部证据

对于固定结构，数据尾部采用条件模型

$$
\hat{L}_s(D) = L_{\infty,s} + B_s\left(\frac{D}{D_{\text{ref}}}\right)^{-\beta}.
$$

并只将 L2 上的高 D 斜率作为局部先验，再以 L6 自己的两个高 D 锚点校准候选。其合理性仅来自
一个相邻结构检查：从 20.972M 增至 118.149M 时，L2 的实际 loss 降幅为 0.6650，L3 为
0.7773；共享尾部指数给出的 L3 降幅为 0.6991，误差 0.0782。这支持“在该局部区间可转移”，
但不等价于验证整个 `Loss(N,D)` 曲面。

## 4. 局限性、失败实验与外推风险

1. **全局律未被证实。** 早期加性律的失效已由冻结盲测量化；18 点重拟合又显示结构留出
   不稳定。当前结论只能是“局部尾部模型在有限桥接检查下可给出 L6 候选”，不能声称找到了
   稳健的普适 `Loss(N_no_embedding,D)`。
2. **目标远离支持集。** 最终 `D/N=1515.109`，而 Stage3 最大独立验证仅为 44.908；目标 D
   为新增 Stage5 最大 D 的 26.97 倍，且为 L6 最大完成 D 的 113.69 倍。尾部饱和、优化失稳或
   参数/数据交互都可能使真实 loss 落在所报经验区间之外。
3. **失败运行不被伪用。** 原始网格中 2 次失败和高数据量校准 Wave C 的 3 次超时均没有
   `final_validation_loss`，未放入拟合表。Wave C 的运行时长（3,000 / 4,800 / 5,500 s）只说明
   原定校准覆盖不足，不能当作 loss 观测或“低 loss 证据”。
4. **小模型数据轴的转移有限。** L2/L3 的桥接仅检验了一段 `D` 变化；将其尾部指数转移至
   L6 是模型假设。比值模型虽然通过了 Stage5 的两项冻结阈值，却仍有结构 LOO MAE 1.3179，
   也不足以替代此处的风险说明。
5. **训练与最终评测可能不同。** 本报告预测的是该训练配方下的远端最终验证 loss；随机性、
   更长训练中的吞吐变化、运行时限制及课程最终评测机制均可能带来额外偏差。
