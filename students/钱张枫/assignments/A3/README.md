## 1. 实验设计

实验按“链路验证—主网格—学习率对照—外推验证—最终稳定性验证”的顺序串行进行：

1. E001 使用极小配置验证配置解析、预算预留、状态轮询和结果读取。由于只有 4 个优化步且带有资源警告，不进入拟合。
2. E002–E008 构成固定学习率 `3e-4` 的主网格。模型规模覆盖 2 层/hidden 128、4 层/hidden 256、8 层/hidden 512，训练 tokens 覆盖 `262144`、`1048576`、`4194304`；sequence length、batch size、评估次数和 model seed 保持一致，用于分离模型规模和训练数据规模的影响。
3. E009–E013、E017 在 8 层/hidden 512、`4194304` tokens 上比较 `2e-4` 至 `7e-4`。E013=`7e-4` 因超时失败；E017 调整评估次数以绕开重复配置限制，恢复了同一训练更新轨迹下的 `7e-4` 结果。
4. E014–E016 分别验证更大模型、更多 tokens 及两者组合；E018 与 E016 仅学习率不同，用于确认 `7e-4` 能稳定迁移到最终候选。
5. E019 是独立长训练校准实验，状态未恢复，不进入任何定量结论。

## 2. 主要结果与 Scaling-law 拟合

### 2.1 关键实验结果

| 实验 | 模型（层数 / hidden） | 训练 tokens | 学习率 | 状态 | 最终验证损失 | 用途 |
| --- | --- | ---: | ---: | --- | ---: | --- |
| E002 | 2 / 128 | 262144 | `3e-4` | completed | 21.021484375 | token scaling |
| E003 | 2 / 128 | 1048576 | `3e-4` | completed | 17.9111328125 | token scaling |
| E004 | 4 / 256 | 1048576 | `3e-4` | completed | 16.40478515625 | model scaling |
| E005 | 8 / 512 | 1048576 | `3e-4` | completed | 15.29150390625 | model scaling |
| E006 | 2 / 128 | 4194304 | `3e-4` | completed | 16.98779296875 | token scaling |
| E007 | 4 / 256 | 4194304 | `3e-4` | completed | 15.25390625 | model scaling |
| E008 | 8 / 512 | 4194304 | `3e-4` | completed | 13.92822265625 | 主网格交叉点 |
| E014 | 12 / 768 | 4194304 | `6e-4` | completed | 12.8505859375 | 模型外推 |
| E015 | 8 / 512 | 16777216 | `6e-4` | completed | 11.19140625 | token 外推 |
| E016 | 12 / 768 | 16777216 | `6e-4` | completed | 10.906982421875 | 组合外推 |
| E018 | 12 / 768 | 16777216 | `7e-4` | completed | 10.857177734375 | 最终候选稳定性验证 |

固定小模型时，连续两个 4 倍 token 区间的损失改善分别约为 `3.1104` 和 `0.9233`；固定 tokens 时，扩大模型也持续降低损失。两条 scaling 轴均有效，但收益随规模增加而递减。

### 2.2 拟合方法与诊断

对固定学习率 `3e-4` 的 E002–E008 拟合归一化联合模型：

```text
L(N, D) = E + A * (N / 1e7)^(-alpha) + B * (D / 1e6)^(-beta)
```

| 参数或指标 | 数值 |
| --- | ---: |
| `E` | 12.095951816 |
| `A` | 3.250722748 |
| `B` | 1.916355369 |
| `alpha` | 0.595281011 |
| `beta` | 0.694062259 |
| RMSE | 0.0831575 |
| R² | 0.9984905 |
| 最大绝对残差 | 约 0.1113 |

拟合仅使用 7 个点估计 5 个参数，残余自由度很低，因此较高的样本内 R² 不能替代外推验证。E014–E018 使用不同学习率，只作为独立的外推和稳定性证据，不直接并入主拟合。E001、E013 和 E019 分别因优化步数过少、失败和状态未恢复而排除。

## 3. 最终配置与预测

- 最终配置摘要：12 层、hidden size 768、6 个 attention heads、head dim 128、intermediate size 3072、`16777216` 训练 tokens、sequence length 1024、train/validation batch size 2、8 次评估、model seed 0、学习率 `7e-4`、AdamW、cosine schedule、bfloat16。
- 最终候选实测 loss：`10.857177734375`；E018 在 488 秒内完成，无资源警告，最后两个验证点仅相差约 `0.0037`。
- 最终 loss 点预测：`10.86`。
- 预测区间：`[10.65, 11.07]`。
- 配置选择和区间构造依据：E018 相对仅学习率不同的 E016 改善 `0.0498`，且没有数值或资源异常。区间综合主网格 RMSE `0.0832`、E016 相对两轴加性预测的绝对残差 `0.1418`、E018 末段变化 `0.0405` 和 E016/E018 学习率差异 `0.0498`；四项平方和开方约为 `0.1765`，最终采用约 `0.21` 的保守半宽度。

## 4. 局限性与风险

- 联合拟合样本少、参数多，样本内指标可能高估模型可靠性。
- 主网格使用 `3e-4`，最终候选使用 `7e-4`，不能把所有实验无条件解释为同一个 scaling law。
- 每个配置只有一个 model seed，无法直接估计跨 seed 方差。
- E013 超时的服务端根因未知；E017 和 E018 只能证明 `7e-4` 在两组已测配置上能够稳定完成。
- E019 状态和预算结算未恢复，不能使用其部分状态推断最终损失。
- 预测依赖有限范围的模型和 token 外推，隐藏最终运行仍可能受到运行环境与数值差异影响。
- 课程数据流固定，结论不应直接推广到其他数据集或训练顺序。
